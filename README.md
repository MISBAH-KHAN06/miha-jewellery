## 📖 About the Project

MIHA Jewellery is a collaborative web development project created by **Misbah Khan and Esha Dawa**.

The website presents jewellery collections through an elegant interface, dedicated category pages, attractive product imagery, and straightforward navigation. It aims to provide a visually appealing browsing experience while establishing a premium jewellery brand identity.

## ✨ Features

- 💍 Dedicated jewellery pages for necklaces, earrings, rings, and bracelets
- 🏠 Homepage featuring MIHA Jewellery branding and navigation
- 🖼️ Product images and decorative backgrounds
- ℹ️ About page introducing the brand
- 📩 Contact page
- 🛍️ Customer, order, and payment-related pages
- 🎨 Custom HTML and CSS styling
- 🌐 Static website deployment through GitHub Pages

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Git installed on your computer
- Visual Studio Code (recommended)

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/MISBAH-KHAN06/miha-jewellery.git
   ```

2. Navigate to the project directory:

   ```bash
   cd miha-jewellery
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

### Deployment

The static website is published using GitHub Pages.

**Live URL:**  
https://misbah-khan06.github.io/miha-jewellery/

To publish future changes, run:

```bash
git add .
git commit -m "Update MIHA Jewellery website"
git push
```

GitHub Pages will publish supported changes after the deployment completes.

## ⚠️ Important Notes

- GitHub Pages hosts static files such as HTML, CSS, JavaScript, and images. It does not execute PHP.
- The included `login.php` file requires PHP-supported hosting to execute.
- Server-dependent login, database, order processing, and payment features require an appropriate backend before they can operate as a complete production system.
- Real payment processing should use a secure payment gateway and server-side verification.
